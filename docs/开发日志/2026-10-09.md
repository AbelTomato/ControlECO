# 开发日志 2026-10-09


## 时间未记录 · 第三轮 UI 反馈：去文案、账单页样式统一、商户可自定义、统计圆环左右总览 + 16 色不重复配色


### 需求（用户反馈，按页拆）

- 首页：删「本月还可以花」；「本月剩余 xx 天」→「xx Day」；删总存款下方「全部账户余额合计」。
- 账单：周期选择删掉「xx年xx月」右侧的 ▽、日期不要被方框框住；详细账单的日期头统一样式
  （浅蓝底、日期在前、星期/今天/昨天在后）；全部/支出/收入 删掉圆箭头、改成"看得出能点"的立体按钮；
  非通知捕获的记录要能自定义商户，并规定有/无商户时的标题与小字排版。
- 统计：日均结余为负要带负号；删两句操作提示；圆环取消选中改为"点任意空白处"，无选中态显示总花费与
  总预算（左右两列、金额在上占比在下）；点图例 = 点圆环上该分类；分类颜色太少导致重复，要更多颜色；
  图例前的圆点改成长条。
- 个人：删顶部「账」头像。

### 实现与决策

1. **文案减法**：首页环内只留金额 + 百分比（环比口径由细环自己表达，不再写"本月还可以花"）；
   剩余天数改「N Day」；总存款下方说明删掉。个人页删头像圆底，只留账本名 + 版本号。
2. **账单页样式**：`PeriodStepper` 去掉 `ArrowDropDown` 与描边 Surface，中间日期退化成裸文字（账单/统计
   共用组件，两页同步生效，两侧 ‹ › 圆钮继续承担"可点"提示）；筛选按钮删 `Refresh` 图标，改
   `Surface(shadowElevation = 3.dp, tonalElevation = 2.dp)` 的立体按钮；日期头 `DayHeader` 统一
   primaryContainer 无描边，文案统一「月日 · 星期/今天/昨天」。
3. **商户可自定义**：`saveTransaction` 增加 `counterparty`（默认空参，旧调用不变），编辑页新增「商户」
   输入框（日期与备注之间、回填原值），快速记账「更多细节」同步补上。显示规则抽成纯函数
   `billRowText(counterparty, categoryName, time, note)`：有商户 → 标题=商户、小字第一行「时间 · 类别」；
   无商户 → 标题=类别、第一行只留时间；备注固定第二行（空则不占位）。
4. **统计页圆环**：中心不写字改由两侧列承担——左「花费」、右「预算」，列内第一行金额、第二行占比。
   决策：**花费列的占比 = 花费 ÷ 预算**（预算列作为基准恒 100%），这样一眼能读出"预算用了多少"，
   超预算时数字转警示红；没有预算时占比显示「—」而不是 0%。
5. **取消选中**：选中态提升到 `StatsScreen`，在页面根节点挂 `detectTapGestures` 清空——点环、点图例行
   由子节点各自消费，故选不出错；空白处（含两侧列、说明文字、卡片留白）点击都回到无选中。
6. **图例**：圆点改 10dp 宽 × 行高的分类色条（`height(IntrinsicSize.Min)` + `fillMaxHeight`），整行可点，
   选中行浅蓝底 + 分类名加粗，与圆环高亮双向同步。
7. **配色**：调色板 10 → 16（明暗两套，色相之外再拉明度差）；新增 `categoryColors(palette, names)`：
   按名字哈希取首选位、被占则线性探测下一个空位，分配按名字排序 → 同屏不重复、与传入顺序和金额排序无关
   （换月换年不跳色）；单名字场景仍用 `categoryColor`。
8. **日均结余**：改为 `(收入 − 支出) ÷ 天数`（原为日均支出），负值自动带负号。
9. **操作提示删除后的抖动**：读数行未选中时用不换行空格（U+00A0）占一行高度，选中出数字时图表不下沉。

### 踩坑与验证

- **写出来的 bug**：`categoryColors` 里 `(0 until size).firstOrNull { !used[(start + it) % size] }` 返回的是
  "探测步数"而不是槽位，导致 `(start + 0) % size` 命中时全部落到 palette[0]（同屏所有分类一个颜色）。
  单测先红后绿地抓到了它——**这就是纯函数单测的价值**（颜色分配在截图上不一定看得出来）。
- 本轮设备未连接（上一轮的 Xiaomi 2602BRT18C 已拔出，无线调试未开、mDNS 也搜不到），
  因此**没有做实机截图走查**：结论以 `assembleDebug` + `testDebugUnitTest`（122 例 0 失败）为准，
  实机观感（圆环两列在窄屏上的留白、立体按钮的投影强度、色条长度）待下一次接上设备再走一遍。

## 时间未记录 · 分类 logo 换成用户提供的 6 个 SVG + 图标可自定义（emoji / 内置 / 相册）+ 高饱和调色板


### 需求（用户反馈）

用发来的 6 个 SVG（购物 / 餐饮 / 交通 / 工资 / 娱乐 / 日用）作为新的分类 logo，其余不变；

### 实现

1. **直接绘 SVG 路径**：新增 `ui/common/GlyphPaths.kt`（脚本从 SVG 的 `path d` 原样抽取，
   viewBox 0 -960 960 960），`Glyph` 增加 6 个 SVG 图形，用 `PathParser` 解析（进程内缓存一次），
   绘制时按「中心对齐 + 等比缩放 + y 轴平移」映射到画布；颜色仍由分类调色板下发（补色即用分类色）。
2. **关键词映射**：餐饮→餐盘、交通→汽车、购物→购物袋、日用→日用瓶、游戏/娱乐→手柄、工资/薪/奖金→工资袋；
   其余（咖啡→碗、居住→房子、医疗→十字、电影/旅行→星、其他→省略号…）保持不变。
3. **自定义图标（DB v6）**：`categories` 新增 `icon` 列（迁移 5→6），规格字符串
   `""` / `EMOJI:🍜` / `GLYPH:BURGER` / `IMAGE:cat_icon_<ts>.jpg`；新增 `data/CategoryIcon.kt`
   负责规格解析、相册图片压缩入库（≤512px）、换图删旧图、删分类清理、160px 解码 + LRU 缓存；
   账单行、编辑交易的分类选择、分类列表统一走新的 `CategoryLogo`。
4. **分类编辑对话框**：新增图标区块——大预览 + 「相册图片」/「恢复默认」+ 14 个常用 emoji 快捷格 +
   任意 emoji 输入框（校验：不含文字、≤8 码点）+ 26 个内置图形网格（选中高亮，按该分类取色预览）。
   取消编辑时清理本次刚导入但没保存的图片，不留孤儿文件。
5. **分类调色板高饱和**：按 36° 色相均分重选 10 色（红→橙→橄榄→绿→青绿→青→蓝→紫→洋红→玫红），
   明暗各一套；饼图/圆环/图标共用，相邻分类一眼可分。

## 时间未记录 · 统计页图表化：可交互柱状图（轴标数字 / 点按与滑动读数）+ 预算 vs 实际双环饼图


### 需求（用户反馈）

统计页要能看柱状图（月视角每日一柱、年视角每月一柱，横竖轴都要简单标记数字；手指点一柱看具体数据，
手指在图上滑动则显示手指当前位置的数据——不能只能点不能滑），柱状图下方是饼状图，
表示各分类**预算占比**与**实际占比**。

### 实现

1. **纯计算独立成 `ui/stats/ChartMath.kt`**（不依赖 Compose，全部可单测）：
   - `monthBars`：按天聚合（含零支出日保持时间连续），横轴每 5 天标一个数字、月末补一格；
   - `yearBars`：12 根柱，横轴标 1–12；
   - `niceCeil`：纵轴上限取整到 1/2/2.5/5×10^n；`axisAmount`：轴数字（0 / 1,250 / 12.5K / 1.5M，无货币符号）；
   - `mergeSlices`：合并「实际支出」与「分类预算」为图例切片（并集去重、按实际降序、只有预算没花销的排后面）；
   - `sharePercent`：占比（零分母保护）。
2. **可交互柱状图 `ExpenseBarChart`**（Canvas 自绘）：左侧纵轴 3 条网格线 + 数字，底部横轴天/月编号，柱顶圆角；
   零支出日画一根发丝刻度保持"每一天都在"的节奏。手势用 `detectTapGestures`（点按选柱）+
   `detectHorizontalDragGestures`（横向拖动跟手读数）：**只有横向拖动才被图表吃掉**，
   纵向滑动交还外层滚动容器，图表不会"卡住"页面滚动；选中柱高亮、其余柱压暗 42%，加一条虚线指示，
   柱顶浮出金额气泡（顶部空间不够自动翻到柱内）。图表上方固定一行读数"日期 · 金额 · 笔数"。
   文字用 `TextMeasurer` 量测并按内容缓存，拖动期间只重画不重组。
3. **双环饼图 `CategoryDonut`**：外环 = 分类预算占比（同分类色 42% 透明度），内环 = 实际支出占比（实色），
   同色上下对照；中心显示实际支出合计；没有预算或没有支出时对应环只留底轨。
   下方 `DonutLegend` 每行给出「实际金额 · 占比」与「预算金额 · 占比」（未设预算明确标注）；
   年视角预算按 12 个月合计，图注里写明口径。
4. **页面重排**：周期步进/切换 → 结论卡（本期支出大字 + 日均 + 收入/结余/退款到账 + "花得最多的一句"）→
   每日/月度支出卡 → 分类预算与占比卡（原分类条形列表被饼图 + 图例取代）。
   数据闸门（null = 未就绪整页不画）与"再点统计标签回到顶部"都保持不变。

### 验证

- `:app:assembleDebug :app:testDebugUnitTest` 通过（106 tests，0 failures）。新增 `ChartMathTest` 10 个用例：
  按天/按月聚合、跨月不串行、时区落格、横轴刻度、纵轴取整与数字格式、切片合并与占比、空数据。
