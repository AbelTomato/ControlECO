# 开发日志与实施计划归档

## 开发日志

- 开发日志按日期整理，统一存放在 `docs/开发日志/` 独立目录中，每天使用一个 Markdown 文件，文件名格式为 `YYYY-MM-DD.md`。
- 每个日志条目都标明实施时间，时间格式为 `HH:mm`（24 小时制），并包含简明概要；同一天有多项工作时，在当天文件中分别记录。
- 迁移历史日志时，若原文没有可靠的具体时分，不得推测补写；应标注“时间未记录”。
- 完成一项任务，或讨论形成明确结论、决策或后续行动项后，及时同步到对应日期的开发日志文件。
- 日志应记录实际完成或确认的内容；未完成事项和待验证事项应明确标注状态，不得写成已完成。

## 实施计划

- 实施计划按日期整理，统一存放在 `docs/实施计划/` 独立目录中。
- 计划文件名格式为 `YYYY-MM-DD-某某计划.md`：日期使用四位年份和两位月份、日期，后缀使用简明计划名称。
- 一个计划使用一个独立文件；实施过程中如范围或方案发生重要变化，应同步更新对应计划。
